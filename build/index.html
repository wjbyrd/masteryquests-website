Private by default

The composer works in your browser.

Faculty selections and generated question data are not sent to a Mastery Quests server. Generated games keep progress and run data in the learner's browser. Nothing is automatically transmitted; a results or CSV file leaves the browser only when the learner intentionally downloads and submits it through an instructor-directed course workflow.
