# Mastery Report 2.0 — Controlled Screenshot Review

These three screenshots are controlled visual profiles used to inspect the new evidence-strength language and layout. They are not student records.

- **Expert Student** — 92% accuracy, 22/24, high-challenge exposure. Expected label: **Mastery Demonstrated**.
- **Average Student** — 75% accuracy, 18/24, advanced exposure. Expected label: **Strong Evidence** with targeted weaknesses.
- **Weak Student** — 42% accuracy, 10/24, advanced plus Repair/Bridge exposure. Expected label: **Strong Evidence** of unstable command.

The crucial interpretation rule is explicit in the report: **Strong Evidence describes the strength of the diagnosis, not whether performance was high or low.** This prevents a long weak run from being mislabeled as "limited" merely because performance was poor, while also preventing tiny perfect samples such as 2/2 from being treated as mastery.
