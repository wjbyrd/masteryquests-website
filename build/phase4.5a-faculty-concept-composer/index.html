Faculty Concept Composer

Choose economic concepts, select the game modes you plan to use, review automatic checkpoint coverage, and generate a populated Mastery Quest without editing JavaScript.

This tool must be opened from the hosted site or a local HTTP server so it can load the template and question assets.

Game details

Use lowercase letters, numbers, and hyphens.

Game modes

Select only the modes you intend to offer. The composer will tell you whether the chosen concepts provide enough questions for each mode.

Choose concepts

Search by concept or description. Course-area filters are independent of any textbook chapter sequence.

Starter combinations

Use a preset as a starting point, then add or remove concepts to match your course.

How to read the concept cards

Practice questions are used throughout the game. Checkpoint questions test readiness at the three checkpoints. Repair and bridge questions support adaptive review after a missed concept. Graph, calculation, and integrated-analysis labels appear only when that special format is actually present.

Checkpoint coverage

The composer automatically uses easy checkpoint questions at Checkpoint One, medium checkpoint questions at Checkpoint Two, and hard checkpoint questions at the Final Checkpoint. All ordinary questions remain available throughout the game.
