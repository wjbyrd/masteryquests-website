````text

- `faculty_exports/general_economics_question_bank.csv`

Use the CSV for systematic analysis and the PDF to inspect presentation, graphs, images, formatting, and faculty readability.

AUDIT EVERY QUESTION

Do not merely sample the bank.

For every fixed question, evaluate the following.

1. ECONOMIC ACCURACY

Check whether:

- the keyed answer is economically correct
- the stem contains an inaccurate premise
- feedback accurately explains the economics
- terminology is used correctly
- calculations produce the keyed result
- graph interpretations match the actual graph
- policy, market, PPF, trade, scarcity, opportunity-cost, or other statements are economically defensible

Flag any item where the keyed answer is wrong or where more than one answer could reasonably be defended.

Do not change a question merely because another wording is possible.

2. STEM QUALITY

Flag:

- ambiguous wording
- missing information
- awkward or unnatural phrasing
- unnecessary complexity
- stems that accidentally reveal the answer
- vague references such as “the chosen output” when the intended value is not obvious
- unnecessary negatives
- double negatives
- grammatical errors that interfere with interpretation
- scenarios where the student must guess what the author meant

Do not flag stylistic preferences that have no meaningful effect on clarity.

3. ANSWER CHOICES / DISTRACTORS

Evaluate whether:

- there is exactly one defensible best answer
- distractors are plausible
- distractors represent recognizable misconceptions where appropriate
- distractors are grammatically compatible with the stem
- one answer is conspicuously longer or more detailed than the others
- correct answers repeatedly stand out because of wording, precision, or length
- choices overlap
- two choices are effectively synonymous
- answer choices unintentionally contain clues

Pay special attention to the previously observed problem where a long, highly qualified answer can become obviously correct against several short distractors.

4. FEEDBACK QUALITY

Check whether feedback:

- explains WHY the keyed answer is correct
- uses the same economics actually tested by the question
- does more than merely repeat the answer
- does not introduce a contradiction
- does not refer to information absent from the question
- is concise enough to be useful during gameplay

Flag missing or weak feedback.

5. DIFFICULTY ALIGNMENT

Evaluate whether the assigned difficulty is defensible.

Do not assume the existing assignment is correct.

Evaluate the cognitive demand actually required.

Use approximately:

REPAIR / BRIDGE
- isolates one misconception or foundational distinction
- provides relatively direct conceptual recovery

EASY
- recognition
- basic definition
- direct single-step application

MEDIUM
- interpretation
- comparison
- application to a scenario
- straightforward calculation requiring conceptual understanding

HARD
- multiple pieces of information
- less obvious application
- graph reasoning
- chained reasoning
- competing plausible distractors

ELITE
- synthesis
- diagnosis
- multi-step reasoning
- interaction of concepts
- requires strong conceptual discrimination

LEGENDARY
- genuine mastery-level synthesis
- multi-step or integrated reasoning
- close plausible alternatives
- cannot be solved primarily through vocabulary recognition or obvious elimination

Flag questions that are materially easier or harder than their assigned level.

Do not inflate difficulty merely because a question contains a graph.

6. QUESTION TYPE ALIGNMENT

Check whether the assigned question type accurately describes the task.

Examples include:

- definition
- interpretation
- calculation
- trap
- diagnostic
````
