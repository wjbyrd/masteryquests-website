# Published Managerial parity

The four public `play/managerial-intelligence-directorate/*/index.html` pages remain the maintained game engines. Their published bank scripts, instructional resources, shared `managerial-parity.js/.css`, and artwork remain the runtime sources. Bank-file headers identify them as generated by Gauntlet Question Bank Publisher from private faculty sources; those private authoring inputs/publisher are not present in this tracked repository and were not reconstructed or edited. The classroom builder derives its pages from these public sources.

`sync.mjs` generates `play/managerial-intelligence-directorate/local-telemetry.js` from the current maintained private telemetry client. It copies the Composer-derived tracker, response-view accumulation, pre-verification snapshot and CSV functions instead of recalculating metrics. The small public integration supplies local run/context state and drops the private transport. It does not create anonymous IDs, queues, additional event rows or network requests.

The sync also ensures one script include before the UI adapter in each public game and generates the Strategy Desk underscore-named background alias from the existing space-named image, byte for byte. The classroom builder strips the public tracker include before installing its private tracker, so rebuilding does not double-wrap telemetry.

## Update and check

From the repository root:

```powershell
node audit_tools/managerial_telemetry_parity/sync-composer-behavior.mjs
node audit_tools/managerial_telemetry_parity/sync-composer-behavior.mjs --check
node audit_tools/published_managerial_parity/check.mjs
node audit_tools/telemetry_data_dictionary/check.mjs
node audit_tools/published_managerial_parity/browser.mjs
```

The first command refreshes Composer-derived private/classroom helpers and the public local adapter; run it only after reviewing semantic changes. For public-only regeneration use `node audit_tools/published_managerial_parity/sync.mjs`. Add `--check` to detect stale generated files without writing them. The generator fails if expected maintained source boundaries disappear. No public engine HTML generation step or bank rebuilding is needed.

Browser tests require Playwright and Microsoft Edge. Set `PLAYWRIGHT_MODULE` to a Playwright package directory if it is not available through normal module resolution. `MQ_EVIDENCE_DIR` can redirect downloads/results. Browser tests serve repository assets locally and block external requests. Visibility/copy/blur signals are controlled test events; selections use actual DOM ranges. Room/stage/completion controls provide bounded lifecycle QA and are not a claim of exhaustive student playthroughs.

The baseline content inventory and pre-implementation audit explain which sources were protected. Historical UI suites were executed unchanged apart from output-directory redirection, before and after. Their old exam assertions assume draft selection immediately increments attempts; the current validated engine scores at commit. Those failures are retained in the results, not rewritten. New tests check the actual draft/revision/commit contract.

## Publication (not executed)

After reviewing the checks and committing the intended changes, use the existing repository deployment workflow:

```powershell
npx wrangler deploy --config wrangler.jsonc --assets .
```

This updates static assets in the existing site deployment and retains the existing classroom gate. No telemetry Worker deployment, new endpoint, secret changes, or D1 migration is needed. If using the alternate `./dist` workflow, first populate a complete site staging directory; do not deploy an empty/partial directory. See `server/classroom-access/README.md` and `.assetsignore` for existing deployment exclusions.


The forced-report download fixture calls the engine's beginRunSession, marks the simulated run ending, and stops the timed clock before replacing gameplay DOM. This invalidates pending next-question callbacks just as a finished run must; it does not change production gameplay. MQ_TEST_FILTER optionally selects named tests for diagnosis.
