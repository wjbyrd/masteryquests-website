# Separately designated research dataset

Use only when a genuine active research purpose requires retaining an export beyond the ordinary governance horizon. This is a deliberate, separately documented decision, not automatic approval or perpetual retention. Raw D1 application telemetry remains subject to its normal policy.

- Purpose / active research project: TO BE DOCUMENTED
- Responsible custodian role: TO BE DOCUMENTED
- Dataset name and immutable version: TO BE DOCUMENTED
- Creation date and original export dates: TO BE DOCUMENTED
- Source telemetry measurement contract(s): TO BE DOCUMENTED
- Source governance/disclosure versions and export sidecar references: TO BE DOCUMENTED
- Restricted storage and copy inventory: TO BE DOCUMENTED
- Access boundary / approved recipients: TO BE DOCUMENTED
- Justification for extended retention: TO BE DOCUMENTED
- Approved extended retention end or review date: TO BE DOCUMENTED
- Disposal method, responsible role and date: TO BE DOCUMENTED
- Approval record and applicable institutional/research procedures: TO BE DOCUMENTED

Do not put credentials, learner records or the dataset itself in this repository template. D1 purge does not erase this separately controlled file, submitted copies or backups. Track all copies and record disposal through their receiving systems. This checklist does not establish legal, institutional or research approval.
