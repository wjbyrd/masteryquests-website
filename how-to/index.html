How To

Build a game. Put it in Canvas. Go deeper only when you need to.

For economics, the fast path is the composer. It generates one self-contained HTML game. Host that file, point Canvas at the public URL, and the activity is live.

Build with the Composer Deploy in Canvas

The fast path

Three jobs. No JavaScript editing required.

01

Compose the game

Name it, choose modes, choose a course area and concepts, review checkpoint coverage, confirm readiness, and generate.

See the six composer steps →
02

Publish the generated package

Keep the game HTML beside its concept-reviews folder so mapped review links work. The ZIP also includes faculty-facing build records. Rename the game file index.html for the simplest GitHub Pages URL.

See the hosting steps →
03

Embed the public URL

The Canvas iframe is the wrapper. There is no second wrapper file to build. Paste the public HTTPS game URL into the iframe and test it in Student View.

See the iframe example →
