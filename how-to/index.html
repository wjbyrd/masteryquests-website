How To

Build the game, deploy it, and go deeper only when you need to.

For economics, the fast path is the Composer. It generates one self-contained HTML game. Host that file, point Canvas at the public URL, and the activity is live. For other subjects or deeper customization, start from the blank faculty template.

Build with the Composer Deploy in Canvas

The fast path

Three jobs. No JavaScript editing required.

01

Compose the game

Name it, choose modes, choose a course area and concepts, review checkpoint coverage, confirm readiness, and generate.

See the six composer steps →
02

Publish the generated game

Host the self-contained game HTML at a public HTTPS URL. Concept Reviews open from the Mastery Quests web library when recommended, so no sibling review folder is required. Rename the game file index.html for the simplest hosted URL.

See the hosting steps →
03

Embed the public URL

Paste the public HTTPS game URL into the Canvas iframe and test the activity in Student View. No second wrapper file is required.

See the iframe example →
