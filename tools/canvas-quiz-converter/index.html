The workflow

1Generate

Use Copilot or another AI tool to draft the formatted quiz text.

2Add images

Have the AI write image-based questions and accurate alt text using the exact image filenames.

3Review

Verify every question, answer, image, alt-text description, feedback statement, and point value.

4Convert

Upload the quiz text and images, then create the QTI ZIP.

5Import

In Canvas, use Settings → Import Course Content → QTI .zip File.
